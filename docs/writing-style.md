# Writing style

Applies to every README, part doc, and comment in this repo.

## Length

Say it once. Cut any sentence that repeats, summarises, or softens the one
before it. If a section survives losing a sentence, lose it.

Document decisions and facts, not reasoning you can infer from the result. The
reader wants to print the part, not follow how it was designed.

## Preferred

Facts over descriptions of facts. Write "0.2 mm layers", not "a fairly standard
layer height".

Imperative for instructions. "Keep the OEM screws", not "you will want to keep
the OEM screws".

Three items in a list only when there are three things.
